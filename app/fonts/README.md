# Nunito

Fonte Nunito do catálogo Google Fonts, servida localmente com `next/font/local`.
Isso permite builds sem conexão com o serviço de fontes e evita pedidos externos pelo navegador.

Origem: https://github.com/google/fonts/tree/main/ofl/nunito

- Arquivo: `Nunito[wght].ttf`, salvo como `Nunito-Variable.ttf`.
